## 四、鏈路自測（每次改動後跑一遍）

### 鏈路一：會員註冊

- [ ] `register.html` 空表提交 → 逐字段報錯
- [ ] 非法郵箱 → 格式錯誤提示
- [ ] 兩次密碼不一致 → 提示不一致
- [ ] 未勾選同意 → 被攔下
- [ ] 重複註冊同一郵箱 → 提示已註冊
- [ ] 正確填寫 → 跳轉 `register-done.html`
- [ ] 展示頁：姓名 / 郵箱 / 電話 / 類型 / 時間 / 會員編號是否齊全

### 鏈路二：購買流程

- [ ] `product-detail.html?code=S1/G2/E3` 三種型號內容正確切換
- [ ] G2 / E3 頁面出現創新模組專區，S1 頁面不出現
- [ ] 數量 +/− → 小計即時更新
- [ ] 「加入採購單」→ 跳轉 `cart.html` 且購物車非空
- [ ] 移除單行 / 清空 → 列表更新
- [ ] 小計滿 5000 → 運費顯示「免運費」，否則 HK$120
- [ ] 未填必填項結算 → 報錯
- [ ] 正確提交 → 跳轉 `order-confirm.html`
- [ ] 訂單頁：訂單號格式 `OB-YYYYMMDD-XXXX`、明細、配送資料
- [ ] 列印按鈕可用
- [ ] 返回首頁再進購物車 → 已清空

### 鏈路三：身份

- [ ] `login.html` 密碼少於 6 位 → 報錯
- [ ] 員工 / 客戶單選切換 → 提示文字變化
- [ ] 正確提交 → 提示成功並回首頁

### 全站

- [ ] 每頁頂部 2px 青色進度條隨滾動變化
- [ ] 當前頁導航高亮正確
- [ ] 移動端（< 960px）漢堡選單展開 + 滾動鎖定 + Esc 關閉
- [ ] 聯繫頁三 Tab 切換正常，投訴 Tab 用警示紅
- [ ] F12 Console 全程無報錯
- [ ] Tab 鍵可遍歷，跳轉連結出現

## 五、對比度求解結果（`docs/contrast.py`）

V1.1 §3.7 聲明的 7 組中，**3 組實測不達標**。已用求解器自動修正：

| 組合 | 規範要求 | 規範值實測 | 求解後 | 狀態 |
|---|---|---|---|---|
| 白字 / 深空藍 | ≥ 7:1 | 16.52:1 | — | ✅ |
| 深空藍字 / 雲白 | ≥ 7:1 | 15.39:1 | — | ✅ |
| 電光青字 / 深空藍 | ≥ 4.5:1 | 8.74:1 | — | ✅ |
| **霓虹紫字 / 深空藍** | ≥ 4.0:1 | **2.90:1** ❌ | `#9558FF` 4.03:1 | ✅ |
| **亮紫字 / 深空藍** | ≥ 4.5:1 | **4.17:1** ❌ | `#AD5EF7` 4.50:1 | ✅ |
| **鋼灰字 / 雲白** | ≥ 4.5:1 | **3.99:1** ❌ | `#667286` 4.53:1 | ✅ |
| 深紫字 / 淡紫 | ≥ 4.5:1 | 11.19:1 | — | ✅ |

|---|---|---|
| 電光青字 / 雲白 | 1.76:1 ❌ | `#00806F` 4.53:1 ✅ |

| 鋼灰字 / 石墨灰 | 3.62:1 ❌ | `#808C9F` 4.55:1 ✅ |
| 成功綠 / 雲白 | 1.93:1 ❌ | `#1D815A` 4.51:1 ✅ |
| 告警橙 / 雲白 | 2.41:1 ❌ | `#D03B00` 4.54:1 ✅ |
| 警示紅 / 雲白 | 3.56:1 ❌ | `#D92C1B` 4.52:1 ✅ |
| 金色 / 雲白 | 2.14:1 ❌ | `#876F29` 4.51:1 ✅ |

**§3.1 深色縱深修正**：藍灰 `#12233F` 與石墨灰 `#1C2530` 亮度差僅 0.0009，肉眼幾乎無差別。
藍灰調整為 `#16294A` 後，與石墨灰的ΔY 提升至 0.0075，層級可辨。

> **重跑方式**：`python docs/contrast.py`
> CSS 中的文字色變量全部由該腳本生成，**修改色值請重跑腳本，不要手改 CSS**。

> **建議**：把求解結果寫回 V1.1 §3.7，讓規範與實現一致。
> 這本身是報告「設計過程中的驗證」章節的好素材 —— **發現並修正自家規範的問題，比照抄規範更能體現深度思考**。
