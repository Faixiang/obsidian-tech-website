## 1 背景（已定案，不需要你重新判斷）

### 1.1 現況

導航右側目前只有一顆「登入」按鈕。購物車 `cart.html` 全站只有 3 個頁面能連到，離開後就回不去；登入後導航也不會顯示身分。

### 1.2 已經存在但沒接上的能力

`auth.js` 與 `cart.js` 早就寫好了渲染邏輯，但 16 個頁面**一個都沒掛載**：

| 檔案 | 已實作的 API | 依賴的掛點 |
|---|---|---|
| `auth.js` `renderSession()` | 讀寫 `obsidian.session` | `[data-session-name]` / `[data-session-box]` / `[data-guest-box]` |
| `cart.js` `render()` | 讀寫 `obsidian.cart` | `[data-cart-count]` |

### 1.3 為什麼不直接用這兩個檔案

`cart.js` 只被 2 個頁面引入，`auth.js` 只被 7 個。要掛到 16 頁就得多加 23 個 `<script>` 標籤。

**所以本任務的硬方針：不新增任何 script 標籤**，把渲染邏輯寫進 `main.js`（16 頁本來就有），直接讀 `localStorage`，不依賴 `cart.js` / `auth.js`。

### 1.4 儲存格式（照此讀取，不要改）

```
localStorage['obsidian.cart']    → 陣列，每項含 { code, qty, ... }，件數 = 各項 qty 之和
localStorage['obsidian.session'] → 物件 { role, name, at }，未登入時不存在
```

## 2 要做的事

### 2.1 改造 16 頁的 header 右側

**現況**：每個頁面的 `.site-header__inner` 最後是一個 `<a class="btn btn--secondary" href="login.html">登入</a>`。

**改為**：

```html
<div class="hdr-actions">
  <a class="hdr-cart" href="cart.html" aria-label="採購單">
    <span class="hdr-cart__icon" aria-hidden="true"></span>
    <span class="hdr-cart__count" data-cart-count hidden>0</span>
  </a>

  <a class="btn btn--secondary" href="login.html" data-guest-box>登入</a>

  <div class="hdr-user" data-session-box hidden>
    <span class="hdr-user__name" data-session-name></span>
    <button class="hdr-user__out" type="button" data-logout>登出</button>
  </div>
</div>
```

**硬要求**：

1. **16 個頁面的這段 HTML 必須逐字相同**（含換行與縮排），不得有任何頁面例外
2. 原本那顆「登入」按鈕加上 `data-guest-box` 屬性後包進 `.hdr-actions`，**不要新增第二顆登入按鈕**
3. `data-session-box` 預設帶 `hidden`，由 JS 控制顯示
4. `data-cart-count` 預設帶 `hidden`，件數 > 0 才顯示
5. 不得改動 `.site-header__inner` 的 grid / flex 結構定義

### 2.2 在 `main.js` 追加一個 IIFE

放在檔案最後，命名 `headerActions()`，行為：

1. 讀 `obsidian.cart`，計算 `qty` 總和，寫入所有 `[data-cart-count]`
   - 總和 > 0 → 移除 `hidden` 並顯示數字；等於 0 → 加回 `hidden`
2. 讀 `obsidian.session`
   - 存在 → `[data-guest-box]` 加 `hidden`，`[data-session-box]` 移除 `hidden`，`[data-session-name]` 寫入 `session.name`
   - 不存在 → 反向操作，`[data-session-name]` 留空
3. 監聽 `window` 的 `storage` 事件，跨頁籤同步
4. 監聽 `[data-logout]` 點擊 → 移除 `obsidian.session` → `location.reload()`
5. **所有 `JSON.parse` 必須包 `try/catch`**，解析失敗視為空資料，不得讓整頁腳本中斷

### 2.3 追加樣式

- `.hdr-actions`：橫向排列，`align-items: center`，`gap` 用既有間距變數
- `.hdr-cart`：圖示 + 角標，圖示用 CSS 畫（`border` 或 `::before` 均可），**不得引入外部圖片**
- `.hdr-cart__count`：小圓形角標，數字用等寬字體；顏色用既有變數 `var(--cyan)` 與 `var(--void)`
- `.hdr-user`：會員名 + 登出按鈕橫排
- `≤ 560px` 時隱藏 `.hdr-user__name` 只留登出按鈕，或整體縮小——**不得讓 header 換行或溢出**

### 2.4 順帶修正一處簡體

`assets/js/auth.js` 的 `renderSession()` 內有：

```js
el.textContent = s ? s.name : '访客';
```

`访客` 是簡體，改為 `訪客`。**只改這一個字串，不動該檔案其他任何內容。**
